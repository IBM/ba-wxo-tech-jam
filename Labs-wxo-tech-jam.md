# IBM watsonx Orchestrate Labs

## 1. Overview

On this page you can find all required information to start with the wxO Labs. 

To run the labs, you will:

1) Need to get local access to the files provided in this GitHub. For this, you can either clone this GitHub or download the content as a .zip file.

2) You can run a script provided in this GitHub to get you set-up for the event. That script will grab your system of record (SOR) credentials and configure your local machine for the event.

3) Before you can start one of the labs, please complete the mandatory lab first: **Introduction to watsonx Orchestrate**. Without that, you will not be able to run the other labs.

4) Finally, you will be ready to pick your lab and start it. The table in section below lists all **watsonx Orchestrate labs** that we currently have. It is recommended that during the Jam, you prioritize the labs in which you are interested most. **You do not have to perform the labs in a specific order**.

In case you have **questions or issues related to a specific lab**, use the **Slack Channel** linked in the table below. For any **broad questions, comments, and feedback** please go to the **[#wxo-tech-jam-main-lobby](https://ibm.enterprise.slack.com/archives/C0CC78DRDC2)** Slack channel.

## 2. Clone this GitHub

While working on the labs, you will require some solution artifacts that can be found in this GitHub. To copy them onto your local machine, there are several options, for example:

**Option 1:** Clone the GitHub using git CLI.

If you have git CLI installed on your local machine, please run this command to clone it:

```
git clone https://github.com/IBM/ba-wxo-tech-jam.git
```

**Option 2:** Download as ZIP file.

If you do not have the git CLI installed, you can download the content of this GitHub as ZIP file:

1. Open **https://github.com/IBM/ba-wxo-tech-jam**.
   
2. Click the green button **Code**.
   
3. Select **Download ZIP**.
   
   ![Download ZIP](DownloadZIP.png)
   
4. Once the download completed, please extract the ZIP onto your local machine.

## 3. Grab your system of record credentials, retrieve wxO tenant's particulars and connect ADK CLI to TechJamAmericas.

To run the labs, you will need your system of record (SOR) credentials. Therefore, you will first grab your SOR user ID and SOR password by using a script.

That script will afterwards instruct you how to configure your local machine for the event. In case you can not or do not want to run the script on your own machine, you alternatively can perform the steps manually. In this case, reach out to the event staff to get more information, for example how to retrieve your SOR credentials manually.

To perform all these steps, follow the instructions mentioned in **[Setup and Event Credentials](lab-guides/Setup%20%26%20Event%20Credentials.md)**.

Hint: In case you have trouble running the script or retrieving your SOR credentials, please contact us in the **[#wxo-tech-jam-main-lobby](https://ibm.enterprise.slack.com/archives/C0CACKBQUJJ)** Slack channel.
